# 要件定義書：CampusLink

## 1. プロジェクト概要
- サイト名：CampusLink（キャンパスリンク）
- コンセプト：高校生同士が勉強、学校生活、進路、趣味について情報やアイデアを共有する掲示板。
- 対象ユーザー：日本の高校生
- 目的：高校生が気軽に情報交換し、他の学生の経験やアイデアから学べる場を提供する。

## 2. ユーザーの課題
学校生活や勉強、進路について相談したり、アイデアを共有したりできる場所が必要な学生を想定する。テーマごとに投稿を整理し、必要な情報を探しやすくする。

## 3. 独自の工夫
- 勉強、学校生活、進路、趣味のカテゴリーで投稿を整理する。
- シンプルで読みやすく、スマートフォンでも使いやすいデザインにする。
- 投稿検索とカテゴリー絞り込みを提供する。

## 4. 機能要件
- ホーム画面に掲示板の概要と投稿一覧を表示する。
- 投稿にタイトル、カテゴリー、内容、投稿者、日付を表示する。
- カテゴリーで投稿を絞り込める。
- キーワードで投稿を検索できる。
- フォームから新しい投稿を作成できる（初期版ではブラウザー内に保存）。
- PCとスマートフォンに対応するレスポンシブデザインを採用する。

## 5. UI / UX要件
- 日本語で表示する。
- 高校生が親しみやすい配色とデザインにする。
- 操作方法を分かりやすくする。
- 投稿フォームで入力内容を確認し、個人情報や不適切な内容を投稿しないよう注意を表示する。

## 6. 技術要件
- フロントエンド：HTML、CSS、JavaScript
- 初期版の投稿保存：ブラウザー localStorage
- 公開環境：Azure App Service
- ソースコード管理：Public GitHub repository

## 7. 今後の拡張
- Flaskによるバックエンド実装
- Azure Table Storageによる投稿データ保存
- Azure Blob Storageによる画像表示・アップロード
- GitHub Actionsによる自動デプロイ

## 8. セキュリティ・運用上の注意
- 公開リポジトリにパスワード、トークン、接続文字列、発行プロファイルを含めない。
- 投稿内容や画像を扱う場合は、入力検証や不適切なコンテンツへの対策を検討する。
- 初期版は学習用プロトタイプであり、実際の個人情報を投稿しない。
